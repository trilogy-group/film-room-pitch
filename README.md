# Film Room pitch

The editable pitch page. Served by GitHub Pages from `main`.

- `index.html` holds the page and, in the `#content` JSON block, every word it shows and says.
- Press **E** on the page to edit any text, reorder or hide sections. Drafts stay in your browser.
- **Publish** commits the new `index.html` to this repository with a fine-grained GitHub token (Contents: read and write on this repo only), bumps the version, keeps the replaced version under `versions/`, and updates `versions/index.html`.
- **S** opens the script drawer, which is also the presenter notes. **P** is presenter mode.

Media in `assets/` is not editable from the page. Replace the files and commit to change them.
